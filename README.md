# 國小四年級教材與試題審查生成系統 (G4-Curriculum)

臺中市梧棲區中正國民小學四年級專屬教材、試題與學習單生成平台，內建嚴謹的 AI 自我檢測與審查機制。

---

## 🌟 核心特色

1. **精準版本對齊**：
   - 📘 **數學**：南一版
   - 📙 **國語**：翰林版
   - 📗 **社會**：康軒版
2. **三階漏斗審查機制**：
   - 🛑 **最低標準（Must-Have）**：符合中年級先備經驗、108 課綱學習表現/內容代碼、教科書版本。**未達標直接打回重置**。
   - ⚠️ **中階目標（Should-Have）**：四年級認知負荷理論（CLT）、SDGs 永續目標、STEAM 跨域。**未達標啟動 RDQ 極簡一鍵選擇訪談修正**。
   - 🌟 **高階目標（Nice-to-Have）**：四年級常見迷思診斷、在地時事情境、18 項議題、媒體識讀。**不勉強，達成時列為加分亮點**。
3. **海線在地情境結合**：
   - 融入臺中港區、梧棲漁港、高美濕地、九降風與風力發電等真實情境。
